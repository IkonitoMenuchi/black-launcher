BLACK — минималистичный Android launcher

Функции:
- показывает приложения с категорией LAUNCHER;
- нажатием открывает выбранное приложение;
- долгое нажатие по приложению: выбрать свою картинку, вернуть оригинал, скрыть;
- меню (⋮): восстановление скрытых приложений, обновление списка;
- назначенные изображения и список скрытых приложений сохраняются локально.

Важно:
- замена иконок действует только внутри BLACK, не меняет значки в MIUI или других приложениях;
- скрытие также действует только внутри BLACK, не удаляет и не отключает приложение;
- для установки/сборки нужен Android SDK Platform 36 и Android Gradle Plugin 9.0.0.
- BLACK объявлен как HOME launcher; после установки выберите его в Настройки Android → Приложения → Приложения по умолчанию → Главный экран (названия пунктов могут отличаться).
